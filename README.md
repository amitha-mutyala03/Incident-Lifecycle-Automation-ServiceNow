# Incident-Lifecycle-Automation-ServiceNow

## 📌 Project Overview

An end-to-end Incident Management lifecycle implementation using ServiceNow.
The project automates incident handling from creation to closure using
Business Rules, Flow Designer, notifications, and access controls.

## 🎯 Objectives

- Automate the incident management lifecycle
- Improve incident assignment and tracking
- Implement automated notifications
- Control user access using ACLs
- Reduce manual effort through workflow automation

## 🛠️ Technologies Used

- ServiceNow
- Flow Designer
- Business Rules
- ACLs
- Notifications
- Incident Management
- Update Sets

## ⚙️ Key Features

- Incident creation and tracking
- Automated incident assignment
- Workflow-based incident processing
- Automated email notifications
- Role-based access control
- Incident lifecycle management

## 🔄 Incident Lifecycle

1. Incident Creation
2. Incident Assignment
3. Incident Investigation
4. Incident Resolution
5. Incident Closure
